# PolicyVisor Insurance Group Reports

Static report site for PolicyVisor Insurance Group (#771), deployed on Vercel. Edition 11-13-26: last 3 months, Aug 13 to Nov 13, 2026.

- `index.html`: report hub (Campaign Reports, Website & Research)
- Campaign Overview, Auto, Home and Home (Weekend) campaign reports
- Monthly Sales by Source & Aid, Source & ZIP Sales (with the ZIP sales CSV), Lead-to-Sale Gap Analysis, Inbound Call Review
- Website SEO audit of policyvisor.com, Pennsylvania flood and winter storm risk, Pennsylvania demographic research and its ZIP data CSV (research content prepared Oct 12, 2026, files re-named for this edition)
- `vercel.json`: clean URLs, security headers, `noindex`, redirects from the 10-12-26 file names

Notes: GOAL receives only Quoted and Sold events (no Contacted pixel), so contact rate is not shown. No Producer Pipeline page: the newest list (Nov 13) has no producer column.
